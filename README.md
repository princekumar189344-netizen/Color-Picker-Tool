# Color-Picker-Tool 

## About This Project

I made this Color Picker Tool as a small web project using HTML, CSS and JavaScript. My main idea was to make a simple page where I can select a color and easily see what color I selected.

The project has a color picker, a large preview area and a section that shows the selected HEX color code. I also added a "Copy Color Code" button so that I can copy the HEX code without typing it manually.

-----

## What I Made

The main things in my project are:

- A color picker for selecting a color
- A large area that shows the selected color
- HEX color code display
- A button for copying the color code
- A simple card-style design

I tried to keep the project simple because I wanted the main focus to be on selecting and copying colors.

-----

## How To Use

1. Open the project in a browser.
2. Click on the color picker.
3. Select any color you want.
4. The large color box changes to the selected color.
5. The HEX code is shown below "Selected Color".
6. Press the "Copy Color Code" button to copy the HEX code.
