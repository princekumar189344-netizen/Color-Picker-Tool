# Color-Picker-Tool

## About 

I made this colour picker tool using HTML, CSS, and JavaScript.

The main Idea was to make a simple tool where I can select a color and and see the selected color on the screen. It also shows the color values like HEX, RGB and HSL.

------

## How I made it 

first time make the basic page using HTML.

I added the colour picker, colour preview and places for showing the color values.

Then I used CSS to design the page and make the buttons and the color preview look better.

After that I used JavaScript to make the color picker interactive. When I select a new color. The preview and color values change.

-----

## Features 

- Different colors available.
- live color preview.
- HEX value.
- **Copy color code** button.
- Simple and clean design.
- Works in a web browser.

-----

## How to Use 

1. Open "index.html" in a web browser.
2. Click on the color picker.
3. Select any color you want.
4. The preview will change to the selected color.
5. The HEX color code will be shown below it.
6. Click **Copy color code** to copy the color code.
