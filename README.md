# Color-Picker-Tool

## About 

Color Picker Tool is a simple web application built by using HTML, CSS, and JavaScript. It allows users to select a color, view the selected color in a preview box, see its HEX color code, and copy the code to the clipboard.

## Features

~ Select colors using a color picker.
~ Live color preview.
~  Display HEX color code.
~ Copy color code with one click.
~ Simple and responsive desgin.

## How its work 

1. The user selects a color from the color picker.
2. The preview box updates instantly.
3. The HEX color code is displayed on the screen.
4. Pressing the copy button copies the color code to the clipboard.
